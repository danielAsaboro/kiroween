# Honesty Rules

These rules apply everywhere: UI copy, documentation, comments, test descriptions and commit messages.

## Advice ban

Never write the words **buy**, **sell**, **bet** or **trade** as an instruction or recommendation anywhere in the UI or docs. The board shows signals and gaps. Interpretation is the reader's job.

## Sample size

Every score card must show **n** (number of settled markets scored). A score card with n < 5 must carry a "low n" warning badge.

## Grading rules

- Grade only against **settled** markets.
- Walk-forward only: each score uses only data available before the scoring hour.
- No lookahead: `fit_at` must be at or before the hour being scored (`fit_at ≤ scored_at`).

## Killed tells

A tell killed under the preregistered kill rule is shown on the board as **killed**, with weight forced to 0. It is never removed from the board history.

## Data provenance

All numbers shown on the board come from `fixtures/omens/board-data.json`.

- This file is generated by the grader pipeline.
- It must **never be edited by hand**.
- If the file contains a value you disagree with, fix the pipeline that produced it, not the file.
